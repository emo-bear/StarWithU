## 星系右上角空白（根因 + 修法）

几何反算（camera z=3.05 / fov45 / TILT_X=0.56 / TILT_Z=-0.2，盘面 → 屏幕）：
- 画面顶部中线对应盘面半径 ≈7 个盘单位，**右上角 ≈33**（视线几乎与盘面平行，接近地平线）。
- `FIELD_OVER=5` 时解析平面半边长 21.5，其 z 向边缘在屏幕上落在 ndc y≈0.88 → 框内一条硬边。**这就是"空一块"的真因**，不是配色问题。

改动（`frontend/src/components/Universe.vue`）：
- `FIELD_OVER` 5.0 → 9.5（半边长 21.5 → 40.8，覆盖 33）。
- 场 shader 加 `1/sqrt(r)` 长尾 `skirt`（系数 0.048，`smoothstep(0.5,0.86,r)` 渐入，低 freq fbm 调幅），外缘偏藕紫、局部透青。原来只有 `exp(-r/0.5)`，r>2 必黑。
- 新增 `rim` 层 15000 点，半径 0.62–1.77 盘单位；`halo` 1400→2800 点、半径放到 ~1.4 盘单位。
- 修 bug：halo 配色 `1 - smooth((r-0.56)/0.3)` 在 r>0.86 直接刷成黑色 → 改 `Math.max(0.2, ...)`。
- `frameGlow` 尺寸从 `planeR*2.4/1.7` 改为 `diskR*12/8.5`（保持原观感，不受 FIELD_OVER 影响）。

## 第二轮：填满 + 装饰星点跟随光晕

用户追加：整个星系要在页面内、尽量填满各区域、空的地方可用装饰星点补；**装饰星点必须围绕光晕分布，不能错开**（明确不是事件点）。

几何关键结论（算了两遍，务必记住）：
- 视角下**整个画面都落在星系外缘**：画面上边 = 4.6 个盘单位、右上角 = 33、下边 = 1.8、右边中点 = 2.6。
- 盘面投影垂直压缩 0.53，且相机距离 ≈ 盘面半径（camZ 3.05），**近半侧会跑到相机后面**。所以"未裁切的完整星系"在这套透视下不可能填满 1.47 宽幅画面：要么星系小、四周靠光晕，要么铺满但边缘被裁。
- `visR = 1/DISK_OVER` 使**点云的最大绝对半径恒等于 corner**，与 DISK_OVER 无关；而解析场的亮盘半径 = `1.03*DISK_OVER*corner` 随 DISK_OVER 变。所以以前 DISK_OVER=1.42 时场比点云大 40% → 出现"有光晕没星"的环。现已对齐。

改动：
- `DISK_OVER` 1.42 → 1.25；`coreR = diskR * 0.437`（跟盘面等比，不再锚 corner）。
- 场 shader：`skirt` → `haze = 0.085/sqrt(1+0.075r²)` × `smoothstep(0.30,1.0,r)` × `(0.45+0.95*fbm(q*1.55))`，颜色藕紫↔青。边框处 ≈16-20/255，右上角 ≈8/255，不再死黑。
- JS 侧 `hazeAt(r)` 复刻同一公式，装饰星点（`rim`, 30000 点，r 0.5~7，pow 1.7 内密外稀）亮度 = `hazeAt(r)/0.078`（下限 0.18）→ 星点自带光晕，不会飘在黑处。
- 点云/云团半径 `visR*1.04→1.33`（≈1.06），sparks 40000；sparks 外缘色衰减改 `max(0.1, 1-smooth((r-0.58)/0.52))`，不再一刀切黑。

## 最终版：右上角填满（已编译 + 像素级验证）

沙箱恢复后做的真实验证，不再是推算：
- 无头 Chrome 1060×720 截图 `shots/b_0.4 / b_2.2 / b_4.1.png`，脚本 `shots/grid.py` 做 8×6 网格平均亮度 + 死黑占比统计。

关键改动（`frontend/src/components/Universe.vue`）：
1. `DISK_OVER = 1.36`（1.42 稍满、1.25 太空，取中间），`coreR = diskR * 0.437`。
2. **掠射角权重**才是「右上角天生黑」的根本解：视线贴地平线看盘面时穿过的厚度是正面 10 倍以上，按理该更亮。shader 里取视线与盘面法线的 |cos|：
   `haze *= clamp(0.52 / max(0.05, cosv), 1.0, 2.8);`
   → 只补外缘（`smoothstep(0.30,1.0,r)` 之后），核心不受影响。
3. `haze = 0.095/sqrt(1+0.055r²) * smoothstep(.30,1,r) * (0.35+1.1*fbm(q*1.55+41))`，颜色藕紫↔青。
4. 装饰星点 `rim` 36000 点：**沿旋臂相位 `armPhi(r, arm)` 排**（78% 贴臂、22% 散在臂间，σ=0.05+0.085r），r 0.85~9.05 pow 1.9，亮度 `max(0.42, hazeAt(r)/0.09)` → 星点成为旋臂往外的点状延续，而不是撒在黑底。

产物：`build/bin/StarWithU.exe`(17M) / `StarWithU-amd64-installer.exe`(8.7M)，`build/bin/data` 已清理。
调参旋钮：`DISK_OVER`（构图松紧）、掠射系数 `0.52 / 上限 2.8`（角部亮度）、`rim` 亮度分母 `0.09`。

## 主页双视图：星云 / 星途（星尾尘）

`frontend/src/components/StarTrail.vue`（新增）+ `App.vue` 顶部居中 tabs（星云 / 星途）+ `Universe.vue` 的 `emit('core')`（点中央光团切星途）。

星途实现要点：
- 曲线：Catmull-Rom 过 7 个控制点（-0.04,0.50 → 0.14,0.55 → 0.35,0.64 → 0.55,0.70 → 0.73,0.59 → 0.88,0.39 → 1.04,0.23），420 采样点带切线/法线，提供 `sample(t)`。
- 厚度 `thickAt(t)=18+66*sin^1.15`，两端细中段厚；事件星 `starT(i,n)=0.09+0.83*i/(n-1)` → **按时间从左到右**；颗粒 `t+time*sp` 取模 → 流动方向也是从左到右。
- **气体不要用描边**：早期用两次 `g.stroke()`（lineWidth 2.6×/1.05×），出来是一张有硬边、发灰的薄片。改为沿曲线摆 170 个柔光团（radius=thickAt*1.5*抖动，alpha≈0.029，加法混合），边缘自然消融、有疏密。
- 精灵必须做边缘遮罩：`maskEdge()` 用 `destination-in` + 径向渐变把四边 alpha 强制为 0，否则事件星放大后能看到方形边界。
  - **坑**：`makeStarSprite` 里十字是用 `translate(s/2,s/2)` 画的，遮罩前必须 `setTransform(1,0,0,1,0,0)` 复位，否则 `fillRect` 只盖住右下 1/4，其余被擦掉 → 事件星整排消失。
  - **坑**：`pickColor()` 每次调用重新随机，用 `findIndex(p=>p.rgb===pickColor())` 反查常得 -1，`drawImage(undefined)` 抛错导致整帧绘制中断（只剩底光）。改为 `pickColorIdx()` 直接返回下标，并 `sprites[i]||sprites[0]` 兜底。
- 加法混色下青/白叠多会发灰：PALETTE 权重调到 粉0.56 / 金0.19 / 藕紫0.13 / 青0.07 / 近白0.05；尘精灵中心白从 0.95 降到 0.62；气体里不掺暖金（大面积软光上金色显脏）。
- 事件星三层绘制（远晕3.6×/主体1.7×/硬核0.62×），size≈23*1.2*(H/720)，alpha 0.22/0.6/0.95 —— 太亮会变成"一排灯泡"。

打包：`build/bin/StarWithU.exe` 17M、`StarWithU-amd64-installer.exe` 9.1M。

## 星途重做：导航纯文字 + 参考图的丝带走势 + 填满留白

**导航**（`App.vue`）：去掉胶囊底板，只剩文字，选中项下面一条 `::after` 横杠——linear-gradient 两端透明、中间亮粉，`width 0→108%` 过渡 + 淡粉外发光。

**尘带形状**（`StarTrail.vue`）：`CTRL` 换成 15 个控制点，走向 = 左端小勾 → 中段隆起 → 右侧摊平 → 收成尖梢（末端 `[1.020,0.700]` 出框）；`THICK` 重排为 `4→57→2`（细→宽片→尖梢，整体只占画面高 ~0.12）。

关键坑与解法：
1. **整条轮廓一次 `fill()` 会在折返处自交、按绕数留黑洞** → 改为沿曲线**逐段填四边形**（STEP=3，两端 fade 收口）。
2. **曲率半径小于半宽时四边形会翻转**（出现倒三角）→ 路径改成不回折的柔波，不做真打结。
3. **低 alpha 粉叠在近黑底上会被稀释成灰紫**（0.17×255≈43，三通道都低）→ 带身渐变 alpha 提到 0.30/0.24/0.155/0.05，且**柔光团改用 `globalCompositeOperation='lighter'`**（加光不会把颜色拉灰），画完复位 `source-over`。
4. **带身硬边** → 柔光团半径放到 `thick*1.6` 并允许溢出轮廓（`off` 抖动到 `th*0.34`），边缘自然化开；上缘棱线 alpha 0.1→0.045。
5. **颗粒只聚在中轴** → `sigma` 三层 0.34/1.15/2.6 → 0.55/1.25/2.7，贴带层越过轮廓把切口咬碎。
6. 内部再补 26 道沿走向的亮流（`sprites[3]`，压扁 0.62）避免整片均匀发闷。

**事件星**：`starT(i,n)=0.06+0.88i/(n-1)` 保时间序，法向散落 `th*(0.22+0.95*hash)` 有正负侧，加 `sin(time*1.1+i*1.7)*2.4` 呼吸 → 围绕尘带散布而非排成一排。

**背景**：900 颗星点 + 34 团哈希星云（外加手补 5 团在底部与左上）。

## 星途重做（二）：从「管道/丝带」改成「透视的路」

需求：从左上角远处舒展到右下角跟前，要有由远及近；像极简道路，中间流光向四周散光点，远端隐没。

**核心是几何律，不是分区调参**：`thickAt(t)` 改成透视律
`h = min(W*0.098, H*0.30) * (0.05 + 0.95*t)` —— 等宽路面在屏幕上的宽度正比于「离消失点的距离」，即正比于 t。
- 先试过 `pow(t,1.55)`（想加强透视），结果宽度全挤在最后一小段爆开，变成一束楔形光；**指数必须≈1.0**。
- 近端宽度 `NEAR_HW` 从 0.17 → 0.098：胖带子永远像丝带，只有细路才像路。

**控制点**：前段笔直（有方向）→ 中段一个缓弯 → 弯过重新走直 → 直插右下角出框（tail 1.13,1.01）。
曲率均匀分布会变成"一道圆弧/一圈"，路必须有直段才读得出来。

**图层顺序**（很关键，否则前面白画）：
路体四边形 → 气体柔光团(rad=h*1.5) → 外晕(rad=h*2.5+26) → **路缘** → 中线光脊 → 流光 → 外散光点 → 尘 → 事件星。

**两个 canvas 真 bug**：
1. `g.globalAlpha = Math.pow(t,1.05) * 1.5` → 超过 1 是无效值，**canvas 直接忽略赋值、沿用上一次的 alpha**（正好是外晕的 0.011），路缘整条消失。所有 alpha 必须 clamp 到 1。
2. 路缘 `fill()` 时 `fillStyle` 还是路体那份渐变（alpha 只有 0.2 量级），globalAlpha 给到 0.9 也没用 → 必须给路缘单独的亮白粉渐变。
3. 路缘要"发光"不能靠一条线：同一路径叠三档宽度（6.5×/2.8×/1×，alpha 0.1/0.3/1）才有外光。3 档×2 边×260 段太耗，边段步长单独用 `ES=4`。

**流光**：`s0` 均匀 → `t = s0^1.5`，远端慢、近端快；沿切线 rotate 后画拉长的精灵（len=h*0.85+10）。

**外散光点**：1500 个无状态粒子，相位 `ph=(seed+time*sp)%1`，法向外扩 `h*(0.4+reach*ph)` + 切向抖动 `jit*h*ph*1.3`，亮度 `(1-ph)²`，所以是"散开→消失"。

**远端隐没**：路体渐变前 15% 完全透明（不是从 0 开始渐亮）；尘/气体/光点的远端淡出分母同步拉到 0.2。事件星起点 0.17。

**尺寸透视**：尘 `size*(0.3+1.05t)`，事件星 `8+26t`，散落幅度 `th*(0.2+0.75*hash)`。

产物 17M exe / 9.1M 安装包。

## 星途第二版：羊角螺线 + 无边界光带

用户反馈两点：**边界太明显**、**路径不够弯**（并要求"查一下有哪些美丽曲线"）。

**中心线换成羊角螺线（Euler spiral / clothoid）**：查下来它就是公路/铁路的缓和曲线，曲率随弧长单调变化（κ ∝ u^(pow-1)），远端曲率趋近 0（像从无限远渗出），越近弯得越厉害 —— 正好等于"由远及近"。实现是直接积分切向角 `θ(u)=θ0+turn·u^pow`，再二分路径长度让它从底边外穿出去（`buildPath`）。定稿 `th0=6°, turn=68°, pow=1, p0=(0.012,0.014), exitY=1.05`，从左上角进、底边 x≈0.87 出。之前手摆 Catmull-Rom 控制点永远调不出"看得见的弯"。

**路面从"填形状"改成"填剖面"，四轮迭代才好**：
1. 撒柔光团叠加 → 外圈层半径 = 5×半宽（≈550px）且重叠 60 层，横截面被外圈压平，整屏成了雾墙。
2. 改成逐段横截渐变条 → 段与段有接缝，出现梯子状亮纹（`halfH` 有重叠时叠出双倍 alpha，无重叠时留下暗缝）。
3. 改成并排细带（每条沿整条路一次画完）→ 沿路没缝了，但**带与带之间**仍有亚像素接缝；且 `globalAlpha` 忘了复位（沿用背景星点的 0.07）导致整条带近乎消失。
4. 最终：光带画在半分辨率离屏画布上再放大贴回，重采样把亚像素接缝全抹平；而且带子不随时间变化，**只在 resize 烘焙一次**，每帧只 `drawImage` 一张图。

**剖面**：`CROSS` 是 0→1→0 的钟形，`BAND` 五层（K=3.0/1.6/1.0/0.55/0.22，peak 0.05→0.28，颜色由外藕粉到内近白）在 `laneStyle` 里按权重相加并混色，得到每一细带的合成 alpha 与颜色；沿路再乘 `apron(t)*(0.08+0.92t^1.5)` 的渐变，远端归零、近端最亮。实测沿线亮度 30 → 130，透视纵深成立。

**踩坑**：`crossAt(u)` 收的是"整条横截面"坐标（0.5 才是中轴），直接传 `|x|/K` 会把剖面画反 —— 中路变暗、两侧两条亮边。

产物 17M exe / 8.7M 安装包。调试：`?mode=trail&demo`，参数可用 URL 覆盖 `?th0=&turn=&pow=&hw=`。
